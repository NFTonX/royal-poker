# ♠️ Royal Poker Club — Telegram Mini App

Полнофункциональное веб-приложение онлайн-покера (Texas Hold'em No-Limit), встроенное в Telegram Mini App, с поддержкой игры в реальном времени, мультиплеером, ботами и покупкой фишек за **Telegram Stars (`XTR`)**.

## 🚀 Особенности

- **Реальный мультиплеер**: Подключение игроков в реальном времени через WebSockets (Socket.io).
- **Покерный движок Texas Hold'em**:
  - Полный цикл раздачи: Префлоп, Флоп, Тёрн, Ривер, Вскрытие (Showdown).
  - Управление банком (Pot) и разделение при All-in (Side Pots).
  - Оценка силы 5-карточных комбинаций (pokersolver).
  - Таймер хода игрока с авто-чеком/фолдом.
  - Игровые боты для тренировки и заполнения столов.
- **Интеграция с Telegram Stars**:
  - Покупка фишек через официальные инвойсы Telegram (`currency: 'XTR'`).
  - Модальное окно покупки с тарифами:
    - ⭐️ 50 Stars ➔ 5,000 фишек
    - ⭐️ 150 Stars ➔ 20,000 фишек
    - ⭐️ 500 Stars ➔ 75,000 фишек
    - ⭐️ 1,000 Stars ➔ 200,000 фишек
  - Мгновенное начисление фишек после оплаты через `successful_payment`.
- **Ежедневный бонус**: +1,000 бесплатных фишек каждые 24 часа.
- **Таблица лидеров**: Рейтинг лучших игроков клуба по фишкам и победам.

---

## 🛠 Структура проекта

- `backend/`: Node.js + Express + Socket.io + grammY (Telegram Bot) + SQLite/JSON DB.
- `frontend/`: React + Vite + Tailwind CSS + Lucide Icons + Canvas Confetti.

## 🌐 Бесплатный запуск и Деплой

### Вариант 1: Бесплатный облачный хостинг 24/7 (Render.com)
1. Загрузите репозиторий на свой GitHub.
2. Зайдите на [Render.com](https://render.com/) и создайте новый **Web Service**.
3. Выберите ваш репозиторий. Render автоматически обнаружит `render.yaml`.
4. Укажите переменные окружения:
   - `BOT_TOKEN`: ваш токен Telegram бота.
   - `APP_URL`: URL, который выдаст Render (например, `https://royal-poker.onrender.com`).
   - `BOT_USERNAME`: `RoyalsPokerBot`.
5. Нажмите **Deploy**. Бот автоматически обновит кнопку меню на ваш публичный URL!

### Вариант 2: Локальный запуск с публичным туннелем (Cloudflare / Localtunnel)
1. Установите зависимости:
   ```bash
   npm run install:all
   npm run build
   ```
2. Запустите сервер:
   ```bash
   npm start
   ```
3. В отдельном терминале запустите туннель:
   ```bash
   npx localtunnel --port 3000
   ```
4. Полученный HTTPS URL скопируйте и укажите в `backend/.env` в поле `APP_URL`.
